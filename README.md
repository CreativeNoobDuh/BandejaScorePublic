# Bandeja Score

This repository hosts the public website and privacy policy for the Bandeja Score Android app.

Bandeja Score is a tennis and padel scorekeeper built around a large landscape scoreboard, Bluetooth remote scoring, voice announcements, two-phone recording, scoreboard overlays, and automatic highlight creation.

- [Privacy Policy](./PRIVACY_POLICY.md)
- [Website](https://creativenoobduh.github.io/BandejaScorePublic/)

## GitHub Pages

If the website is not live yet, enable it from the repository settings:

1. Open `Settings`.
2. Open `Pages`.
3. Set source to `Deploy from a branch`.
4. Choose `main` and `/root`.
5. Save and wait for GitHub Pages to deploy.
